## 🚀 How to Use

### Viewing the Portfolio Online
Visit the live portfolio at: **https://sujanportfolio.com**

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kcsujan877-png/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000`

### Building for Production
```bash
npm run build
npm start
```

## 📝 Customizing Your Portfolio

### Update Personal Info
Edit `src/data/personal.js`:
```javascript
export const personalInfo = {
  name: "Your Name",
  title: "Your Title",
  email: "your@email.com",
  // ... more details
};
```

### Add New Projects
Edit `src/data/projects.js`:
```javascript
{
  id: 4,
  title: "Your Project",
  description: "Project description",
  technologies: ["Tech1", "Tech2"],
  demoUrl: "https://demo.com",
  githubUrl: "https://github.com/...",
  image: "/images/project.jpg"
}
```

### Update Skills
Edit `src/data/skills.js` to add or modify skill categories.
